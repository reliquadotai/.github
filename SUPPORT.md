# Reliquary support

Reliquary is an open-source protocol and operator ecosystem. Use the narrowest
public channel that fits the request, and never publish credentials, wallet
material, private prompts, raw completions, personal data, or private
infrastructure details.

## Start with the source of truth

- [Live network dashboard](https://www.reliqua.ai/dashboard)
- [Network status](https://www.reliqua.ai/status)
- [Protocol concepts](https://github.com/reliquadotai/reliquary/blob/main/docs/concepts.md)
- [Miner guide](https://github.com/reliquadotai/reliquary/blob/main/docs/mining.md)
- [Validator guide](https://github.com/reliquadotai/reliquary/blob/main/docs/validating.md)
- [Fleet documentation](https://github.com/reliquadotai/reliquary-fleet#readme)

## Where to ask

| Request | Destination |
| --- | --- |
| Protocol bug or documentation defect | [`reliquary` issues](https://github.com/reliquadotai/reliquary/issues) |
| Fleet installation, monitoring, or release issue | [`reliquary-fleet` issues](https://github.com/reliquadotai/reliquary-fleet/issues) |
| Organization profile or shared template issue | [`.github` issues](https://github.com/reliquadotai/.github/issues) |
| Research or protocol experiment | [Research proposal](https://github.com/reliquadotai/.github/issues/new?template=research_proposal.yml) |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not open a detailed public issue |

Historical Ledger, Forge, and Protocol repositories are maintained as
references. Reproduce production problems against the canonical
[`reliquary`](https://github.com/reliquadotai/reliquary) repository before
reporting them there.

## Make a report actionable

Include:

- the affected repository and exact release, commit, or image identifier;
- the relevant network, window, or finalized block when applicable;
- expected and observed behavior;
- minimal reproduction steps;
- sanitized logs and screenshots;
- checks already attempted.

Use text or searchable logs in addition to screenshots. Remove tokens, host
addresses, wallet material, authorization headers, raw model outputs, and other
private data.

Public issue trackers do not provide emergency operational response, guaranteed
uptime, profitability advice, wallet recovery, or individualized infrastructure
administration.
