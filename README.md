# Reliquary organization defaults

This public repository powers the
[`@reliquadotai`](https://github.com/reliquadotai) organization profile and
provides shared contribution defaults for Reliquary repositories.

## What lives here

- [`profile/README.md`](profile/README.md) — public organization homepage
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — contribution and evidence standards
- [`SECURITY.md`](SECURITY.md) — coordinated vulnerability reporting
- [`SUPPORT.md`](SUPPORT.md) — support boundaries and issue routing
- [`LICENSE.md`](LICENSE.md) — license for this profile, its templates, and assets
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) —
  organization-wide pull request checklist
- [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE) — bug and research issue
  forms

Production protocol changes belong in
[`reliquadotai/reliquary`](https://github.com/reliquadotai/reliquary).
Operator-dashboard changes belong in
[`reliquadotai/reliquary-fleet`](https://github.com/reliquadotai/reliquary-fleet).

## Editing the public profile

Keep the profile concise, accessible, and evergreen:

- link changing network values to the
  [live dashboard](https://www.reliqua.ai/dashboard) instead of copying them;
- distinguish deployed behavior, measured observations, and proposals;
- keep production repositories separate from historical references;
- store profile media under `profile/assets` with descriptive alternative text;
- verify every public link before merging.

See [CONTRIBUTING.md](CONTRIBUTING.md) before proposing a change.
